Notun ekta open source project banalam: **ModelPort**.

Flutter app e AI model chalate gele asol kaj model na, tar charpasher kaj: model convert kora, input shape khoja, Dart e image preprocessing likha, boro file download ar cache kora. Ar preprocessing e ektu bhul hole app crash kore na, sudhu result ektu kharap hoy, keu dhoreo na.

ModelPort ei kaj gulo kore dey:

✅ Python e 3 ta command e PyTorch / Hugging Face / GGUF model ready
✅ Flutter e ek line e model load ar run
✅ Phone er output Python er sathe mile kina, `checkGolden()` diye proman
✅ Download resume, sha256 check, offline o chole
✅ ONNX Runtime, ExecuTorch, llama.cpp: je engine lagbe sudhu setai

2019 er ekta OPPO phone e test korechi: ExecuTorch e MobileNetV3 17 ms e, ar SmolLM2 diye puro offline chat.

Docs: https://ayanparvaiz.github.io/modelport/
