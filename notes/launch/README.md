# Launch kit

Launch er sob draft ekhane. Egulo tumi nije post korbe. Sob link kaj korbe pub.dev ar PyPI te publish korar por.

## Order

1. pub.dev e 5 ta package ar PyPI te CLI publish (dekho root er `RELEASE.md`)
2. GitHub release `v0.1.0` (demo APK shoho) draft theke publish
3. Blog post: dev.to ba Medium e `blog-post.md`
4. Same din: Reddit r/FlutterDev (`reddit-flutterdev.md`), X ar LinkedIn (`social.md`)
5. Porer din: Hacker News "Show HN" (`show-hn.md`), sokal 8–10 ta US Eastern time
6. Bangladesh: Facebook Flutter group gulo te `facebook-bangla.md`
7. fluttergems.dev e submit, awesome-flutter e PR
