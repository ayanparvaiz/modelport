# modelport (Python CLI)

Prepare models for Flutter apps. Part of [ModelPort](https://github.com/ayanparvaiz/modelport).

> **Status: early development.** Not ready for use yet.

The CLI converts PyTorch, Hugging Face, and GGUF models into mobile formats, checks that the converted model gives the same output as the original, and writes a `modelport.json` manifest that the ModelPort Dart packages read.
